# فصل حزم الحلقات (1–13) — تصميم وقرارات

## المشكلة

ملف ترجمة واحد يحمل حلقات موسم كامل (`S01E01-E13`، `1-13 Complete`, `Batch`). العَرَض الذي رآه المستخدم: الخيار يظهر، والترجمة تظهر، لكنها **ترجمة الحلقة الأولى** سواء اختار «عربي جاهز» أو «AI». ملف مفصول لكل حلقة (Overlord) يعمل بشكل طبيعي.

التشريح:

| طبقة | السلوك القديم | الأثر |
|---|---|---|
| `parseSubtitle` | `cues.sort((a,b) => a.start - b.start)` | كل حلقة تعيد التوقيت إلى `00:00` ⇒ الأسطر تُخلط: E1+E2+…+E13 فوق بعض في نافذة 24 دقيقة |
| `isMultiEpisode` | `≥150 سطر && span > 50 دقيقة` | الامتداد المقاس بعد الفرز = 24 دقيقة ⇒ **لا يُكتشف شيء** |
| `handleReady` | `buildVtt(parseSubtitle(text))` | يُصبّ الملف كاملاً كما هو، فيعرض المشغّل أول سطر = الحلقة 1 |
| `ensureBoard` | `tidy(parseSubtitle(raw))` | يترجم الملف كاملاً ويحتفظ بتوقيتاته المكدّسة |
| `byName` / `verdictFor` | علامة `S01E01` وحدها | يحكم `wrong` على حزمة تحتوي الحلقة المطلوبة، فيُبحث في حلقات مجاورة بلا داعٍ |

الحارس القديم كان **صحيحاً للشكل الثاني** (توقيت متصل > 50 دقيقة) لكنه أخطأ الشكل الأكثر شيوعاً، وأخطأ أيضاً الأفلام الطويلة: فيلم 120 دقيقة بـ 1500 سطر كان يُرفض كأنه حزمة.

## الحل

وحدة واحدة `lib/pack.mjs`، تُستدعى من **كل** المسارات بذات المعطيات، حتى لا يبقى مدخل آخر للحزمة:

```
parseSubtitle(raw, { ordered: true })   ← ترتيب الملف، لا ترتيب الزمن
        ↓
selectEpisode(cues, { id, name, enabled })
        ↓
{ pack:false } | { pack:true, ok:true, cues, episode, method } | { pack:true, ok:false, reason }
        ↓
tidy / buildVtt / createBoard  —  كلها على أسطر الحلقة المطلوبة فقط
```

### كشف الحدود (بالأولوية)

1. **`reset`** — رجوع زمن ≥ 4 دقائق بعد 7 دقائق على الأقل و 20 سطراً ⇒ بداية حلقة جديدة. هذا يمسك الحزم التي تعيد `00:00`.
2. **`labels`** — عناوين `Episode N` / `第N話` / `الحلقة N` / `S01E0N` داخل الأسطر، بشرط 20 سطراً بين عنوان وآخر حتى لا يقطع ذكرٌ عابر في الحوار.
3. **`gaps`** — فجوة ≥ 5 دقائق بين سطرين في ملف متصل التوقيت.
4. **`division`** — إن ذكر الاسم مدى (`E01-E13`) والتوقيت متصل، يُقسّم الزمن إلى `N` حلقات، **فقط** إذا كانت النتيجة 8–60 دقيقة/حلقة و `N ≤ 60`.

اختيار المقطع: `index = episode - from` من اسم الملف، أو شاهد صريح داخل أول 40 سطراً من كل مقطع، أو ترتيب المقطع (= رقم الحلقة) إن غاب المدى. ثم تُطرح بداية المقطع من كل التوقيتات (`normalize`) وتُرتّب داخل المقطع.

### رفض آمن بدل تخمين

| الحالة | النتيجة |
|---|---|
| حزمة لفيلم (معرّف بلا موسم) | إشعار: لا يمكن اختيار حلقة |
| الحلقة المطلوبة خارج عدد المقاطع | إشعار بعدد الحلقات |
| توقيت متصل > 90 دقيقة بلا أي دليل | إشعار: تعذّر تحديد الحدود |
| الخيار `pk` معطّل | إشعار: الحزمة لا تُعرض إطلاقاً |
| فيلم طويل ≤ 6 ساعات بلا دليل حلقات | **ملف عادي**، لا يُرفض (إصلاح خطأ قديم) |

الإشعارات تُرسل كمسار VTT `top` يتكرر كل 90 ثانية، لأن المشاهد قد يكون في أي موضع من الفيديو.

### تغييرات مساندة

- `parseSubtitle(raw, { ordered: true })` و `parseAss(..., { ordered: true })`: الخيار الافتراضي يبقى الفرز الزمني، فلا يتأثر أي مسار آخر.
- `packRange` + `verdictFor` في `lib/episode.mjs`: مدى `S01E01-E13` شاهد **إيجابي** للحلقة الواقعة داخله، لا إدانة من أول علامة؛ مدى من موسم آخر يبقى `wrong`.
- `keyOf` أضيف إليه `ref.i` و `cfg.pk`: رابط الحزمة الواحد لم يعد يُخزّن ترجمة واحدة لكل الحلقات، وإيقاف الفصل لا يخدم ترجمة محفوظة من مقطع مفصول.
- أسماء الخيارات: `… · حزمة 1–13 · حلقة 3` — الشفافية للمستخدم بدل تغيير صامت.
- الخيار `pk` في `/configure` يعمل **افتراضياً**؛ إيقافه يعني «لا تعرض الحزمة» لا «اعرضها كما هي».

## الاختبارات

12 اختباراً جديداً (7 وحدة + 5 عبر HTTP):

- قراءة بترتيب الملف تحفظ الحدود، والقراءة المرتّبة تدمجها؛
- `S01E01-E13` ⇒ `same` للحلقة 3، و `wrong` لموسم آخر؛
- حزمة تُعيد التوقيت ⇒ الحلقة 3 وحدها، 60 سطراً، أول توقيت `0`؛
- حزمة متصلة 13 حلقة ⇒ تقسيم زمني ⇒ الحلقة 3 وحدها؛
- عناوين `Episode N` ⇒ فصل بلا اسم مدى؛
- فيلم طويل بلا دليل ⇒ لا يُرفض؛
- فيلم/حلقة خارج المدى/خيار معطّل ⇒ إشعار عربي؛
- عبر HTTP: القائمة + `/r/` + `/t/` (ترجمة كاملة 60 سطراً) + `/t/` مع `pk:0` + حزمة متصلة.
