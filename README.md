## نظرة سريعة

| البند | القيمة |
|---|---|
| **النوع** | إضافة `subtitles` لـ Stremio / Nuvio، بلا كتالوج وبلا واجهة خاصة |
| **الوظيفة** | يعثر على ترجمة مطابقة لملفك، ويترجمها إلى العربية، أو يمرّر ترجمة عربية جاهزة كما هي |
| **التشغيل** | `node server.mjs` على جهازك، أو Worker واحد + مساحة KV على Cloudflare (الخطة المجانية تكفي) |
| **المفتاح** | مفتاح مزوّد الذكاء الاصطناعي يبقى داخل رابط الإضافة؛ الخادم لا يخزّنه ولا يسجّله |
| **المصادر** | OpenSubtitles + اختيارياً SubDL و Jimaku و Popcorn Notes؛ ومعرّفات Kitsu / MyAnimeList / AniList للأنمي |
| **المزوّدون** | أي خدمة تدعم `/chat/completions` بصيغة OpenAI (Gemini و OpenRouter و OpenAI وإعداد مخصّص) |
| **الصيغ** | SRT · WebVTT · ASS/SSA · ZIP |
| **الترخيص** | MIT |

## المعمارية

```text
   ┌────────────────────┐     manifest / subtitles      ┌─────────────────────────────┐
   │  Stremio · Nuvio   │ ────────────────────────────▶ │  ترجمان (Node أو Worker)    │
   │                    │ ◀──────────────────────────── │  lib/app.mjs                │
   └────────────────────┘     JSON list + WebVTT        └──────────────┬──────────────┘
                                                                       │
              ┌──────────────────────────────┬─────────────────────────┴──────────────┐
              ▼                              ▼                                        ▼
   مصادر الترجمة                    مزوّد /chat/completions                 التخزين
   OpenSubtitles · SubDL            Gemini · OpenAI · OpenRouter          KV (Cloudflare)
   Jimaku · Popcorn Notes           أي مزوّد متوافق                       أو قرص (Node)
```

| الملف | الدور |
|---|---|
| `lib/app.mjs` | كل مسارات الإضافة ومنطق القائمة والترجمة |
| `lib/board.mjs` | لوحة الترجمة: الدفعات، السياق، التقدّم، استئناف العمل |
| `lib/sources.mjs` · `lib/extraSources.mjs` | المصادر الرئيسية والإضافية، بمهلات مستقلة لا تعطّل القائمة |
| `lib/subs.mjs` | قراءة SRT / WebVTT / ASS وكتابة WebVTT |
| `lib/episode.mjs` · `lib/pack.mjs` | حارس الحلقة الخاطئة وفصل حزم الحلقات |
| `lib/config.mjs` | ترميز الإعدادات داخل الرابط، و`safeFetch` لكل طلب خارجي |
| `server.mjs` · `worker.mjs` | منصّتا التشغيل: Node و Cloudflare Worker |
| `build.mjs` · `deploy.mjs` | بناء الحزمة ونشرها مع ربط KV وتفعيل Workers Logs |
| `public/configure.html` | صفحة الإعدادات |
| `test/` | 269 اختباراً، منها اختبارات داخل محرّك workerd |
| `.github/workflows/` | CI لكل push، و Release لكل وسم `v*` |

الإعدادات تُرمّز بـ base64url داخل أول جزء من الرابط: `/<settings>/manifest.json`. لذلك **الرابط سرّ** ويُعامل كما يُعامل مفتاح API.

## التشغيل السريع

**المتطلبات:** Node.js ≥ 20.15. تشغيل السيرفر لا يحتاج أي حزمة خارجية؛ `npm` يلزم فقط للاختبار والبناء.

```bash
git clone https://github.com/Albrall/turjuman.git
cd turjuman
npm ci
npm test          # 269/269
npm run build     # يولّد cloudflare/_worker.js و cloudflare/tarjuman-cloudflare.zip
npm start         # أو: node server.mjs
```

ثم افتح <http://127.0.0.1:7000/configure>، اختر المزوّد، ألصق مفتاحك، اضغط **«جرّب الإعدادات»** ثم **«نسخ الرابط»**.

**التثبيت في المشغّل**

| المشغّل | الطريقة |
|---|---|
| **Nuvio** | الإضافات ← Addon URL ← ألصق الرابط المنسوخ ← Install Addon |
| **Stremio** | زر «تثبيت في Stremio» في الصفحة، أو ألصق الرابط في بحث الإضافات |

> ⚠️ انسخ **الرابط الكامل** من الصفحة، لا عنوان الصفحة نفسه. Nuvio يضيف `/manifest.json` إلى أي عنوان يُلصق؛ من ألصق العنوان المجرد ثبّت نسخة «بلا إعدادات» لا تترجم، وتخبرك بذلك في اسمها وفي قائمة الترجمات. وأي تعديل في الإعدادات يعني رابطاً جديداً يُثبَّت بدل القديم؛ في Nuvio افتح زر ⚙ بجانب الإضافة، عدّل، انسخ، ثبّت، ثم احذف النسخة السابقة.

## النشر على Cloudflare

الخطة **المجانية** تكفي لاستخدام منزل واحد. طريقتان:

<details>
<summary><strong>أ) من لوحة Cloudflare — رفع ملف ZIP</strong></summary>

1. أنشئ حساباً في <https://dash.cloudflare.com/sign-up>.
2. **Workers & Pages** ← **Create application** ← **Get started** ← اسحب `cloudflare/tarjuman-cloudflare.zip` (يُبنى بـ `npm run build` أو يُنزّل من [الإصدارات](https://github.com/Albrall/turjuman/releases)).
3. **Workers KV** ← **Create instance** ← اختر اسماً.
4. في مشروعك: **Settings** ← **Bindings** ← **Add** ← **KV namespace**، واكتب اسم المتغيّر `CACHE` بالضبط.
5. أعد النشر مرة أخرى بالملف نفسه (الربط لا يسري إلا بعد نشر جديد).
6. افتح العنوان: في الصفحة يجب أن ترى «التخزين متصل» و«مصدر الترجمات يرد».

</details>

<details>
<summary><strong>ب) بأمر واحد — موصى به</strong></summary>

```bash
CLOUDFLARE_API_TOKEN=… node deploy.mjs
```

ينشئ Worker باسم `tarjuman` ومساحة KV باسم `tarjuman-cache` ويربطهما باسم `CACHE`، يفعّل **Workers Logs** (100% sampling) لقياس `cpuTime` و `wallTime`، ثم يطبع العنوان. إعادة تشغيله تحدّث الـ Worker نفسه فقط، ولا يمسّ أي مورد آخر في الحساب، ولا يكتب الرمز في أي ملف. يحتاج الرمز صلاحيتي **Workers Scripts** و **Workers KV Storage** (+ **Workers Observability** للسجلات).

</details>

### حدود الخطة المجانية

| المورد | الحد | ما اتُّخذ في الكود |
|---|---|---|
| حجم الـ Worker | 64 MiB غير مضغوط | الحزمة الفعلية ≈ 204 KB (0.3% من الحد) |
| المعالجة لكل طلب | 10 ms CPU | قياس فعلي عبر Workers Logs؛ الانتظار على الشبكة لا يُحسب |
| الطلبات الفرعية | 50 لكل طلب | `HELPER_BUDGET = 32` يترك هامشاً للمصادر و KV |
| الاتصالات المفتوحة | 6 | `maxConcurrency = 5` + اتصال لـ KV |
| الطلبات يومياً | 100 ألف | كافٍ لاستخدام منزلي |
| كتابات KV يومياً | 1,000 | ≈ 4–6 كتابات لكل ترجمة مكتملة |
| قراءة الملفات | — | سقوف 1 MB نص / 2 MB مضغوط / 4 MB بعد الفك، وحماية من zip bomb |

التفصيل الكامل والقياسات في [docs/CAPACITY-ar.md](docs/CAPACITY-ar.md).

### متغيّرات البيئة

| المتغيّر | الغرض | الافتراضي |
|---|---|---|
| `PORT` | منفذ السيرفر (Node) | `7000` |
| `PUBLIC_URL` | العنوان العام إن لم يُستنتج من الطلب | يُستنتج |
| `CACHE_DIR` | مجلد الترجمات المكتملة (Node) | `./cache` |
| `CACHE` | ربط مساحة KV (Cloudflare) | بلا حفظ |
| `ALLOW_LOCAL_AI` | `1` للسماح بمزوّد محلي أو عبر http (Ollama مثلًا) | غير مفعّل |
| `HELPER_BUDGET` | عدد طلبات النموذج في الطلب الواحد | `32` |
| `LINGER_MS` | استمرار الترجمة بعد إجابة الطلب | `18000` |
| `EXTRA_TIMEOUT_MS` | مهلة انتظار المصادر الإضافية قبل عرض القائمة (500–8000) | `3000` |
| `NOTICE` | رسالة أعلى صفحة الإعدادات | لا شيء |
| `TRUST_PROXY` | `1` لقراءة `x-forwarded-host/proto` خلف بروكسي موثوق | غير مفعّل |
| `CLOUDFLARE_API_TOKEN` · `CLOUDFLARE_ACCOUNT_ID` · `WORKER_NAME` · `KV_TITLE` | تستخدمها `deploy.mjs` وحدها | — |

أمثلة الضبط المحلي في [`.env.example`](.env.example)؛ أمّا ربط `CACHE` فهو binding في لوحة Cloudflare لا متغيّر بيئة.

## كيف تعمل الترجمة

1. يطلب المشغّل القائمة، فتُجلب الترجمات من OpenSubtitles ومعها اختيارياً SubDL و Jimaku، وتُرتّب حسب اسم ملفك وبصمته.
2. تُعرض أفضلها تحت «العربية»؛ «عربي جاهز» يُمرَّر مباشرة، وخيار `AI` يبدأ الترجمة.
3. قبل أي سطر، يقرأ النموذج الترجمة كاملة **مرة واحدة** ويستخرج الأسماء والأماكن والمصطلحات المتكررة.
4. تُرسل الأسطر على دفعات، ومع كل دفعة الأسماء الواردة فيها ورسمها العربي، والأسطر السابقة واللاحقة للسياق.
5. تُحفظ الترجمة المكتملة، فالمشاهدة التالية فورية وبلا تكلفة.

إن لم تكتمل خلال مهلة الانتظار، يظهر ما تُرجم والباقي بلغته الأصلية مع تنبيه؛ أعد اختيار الترجمة بعد قليل لتحميلها كاملة.

## قدرات الترجمة

<details open>
<summary><strong>الأسماء والسياق</strong></summary>

- الاسم يُكتب بنطقه لا بمعناه: «Hope» تبقى «هوب» لا «أمل»، و«Mr. Stone» يبقى «السيد ستون»؛ والكلمة نفسها تُترجم حين لا تكون اسماً.
- من يُنادى بصفته (سنّه، رتبته، عمله، قرابته) تُترجم صفته: «Old-timer» تصير «العجوز»، و«Master Roshi» تصير «المعلم روشي».
- شخصيات الأعمال المعروفة تُكتب بالأسماء التي يعرفها المشاهد العربي (غوكو، بيكولو)، والـ g القاسية في الأسماء اليابانية تُكتب «غ».
- الرسم نفسه من أول العمل إلى آخره، لأن كل الدفعات تأخذه من القائمة ذاتها؛ وجنس الشخصية يُستخدم في تصريف الأفعال والضمائر.
- إن عاد سطر باسم مترجم أو برسم آخر، يُطلب ذلك السطر مرة ثانية. هذا يكلّف طلباً إضافياً واحداً لكل فيديو ويمكن إيقافه من الإعدادات.

</details>

<details>
<summary><strong>قاموس أسماء المسلسل (للأنمي)</strong></summary>

للمسلسلات المصنّفة أنمي فقط، وحين تكون «قراءة الأسماء» مفعّلة: يبحث ترجمان عن المسلسل في AniList بالاسم والسنة، ويأخذ أشهر شخصياته (حتى 80، مع الجنس)، ثم يحفظ القائمة حيث تُحفظ الترجمات. في كل حلقة لاحقة: الرسم والجنس يخرجان من القائمة نفسها، والرسوم العربية التي اختيرت أول مرة تُحفظ بدل أي رسم جديد. إن لم يتطابق العنوان أو اختلفت السنة بأكثر من سنتين أو تعذّر الوصول، تتم الترجمة كما كانت تماماً — الفشل صامت ولا يكلّف الحلقة شيئاً.

</details>

<details>
<summary><strong>الأنمي: Kitsu و MyAnimeList و AniList</strong></summary>

يفهم ترجمان `kitsu:<id>[:<حلقة>]` و `mal:<id>[:<حلقة>]` و `anilist:<id>[:<حلقة>]` إلى جانب `tt<imdb>[:<موسم>:<حلقة>]`. يعرف العمل والحلقة عبر Kitsu و AniList GraphQL (كلاهما بلا مفتاح)، فيُعرض لأنمي من هذه الكتالوجات قائمة ترجمات كأي عمل آخر. حارس الحلقة الخاطئة يتنحّى عن صيغ الأنمي، وباقي السلوك كما هو.

</details>

<details>
<summary><strong>مصادر ترجمة إضافية</strong></summary>

بجانب المصدر الرئيسي، يمكن تفعيل مصدرين بمفاتيح مجانية من صفحة الإعدادات:

| المصدر | ما يميزه | ملاحظة |
|---|---|---|
| **SubDL** | قاعدة واسعة تشمل الفانساب، بحث بـ IMDb ثم الاسم والسنة | المجاني: 2000 بحث و50 تنزيلاً يومياً؛ النتائج غالباً ZIP ويُفك تلقائياً |
| **Jimaku** | متخصص في الأنمي، يفهم معرّف AniList مباشرة ويعبر من kitsu/mal عبر mappings و GraphQL | ملفاته غالباً ASS |

بدون مفاتيح تُتخطى هذه المصادر صامتاً، وأي فشل فيها لا يُسقط القائمة الرئيسية: المصادر الإضافية تُنتظر **3 ثوانٍ** كحد أقصى ثم تُعرض ما وصل (`EXTRA_TIMEOUT_MS` لضبطها).

</details>

<details>
<summary><strong>أغاني البداية والنهاية</strong></summary>

أي ثلاثة أسطر متتابعة أو أكثر تحمل إشارة موسيقية (♪) تُترك بلغتها الأصلية ولا تُرسل إلى النموذج. باقي الحلقة يُترجم كالمعتاد، والمشهد يُقدَّم كاملاً بالتوقيت نفسه — توفير لطلب متكرر في كل حلقة.

</details>

<details>
<summary><strong>الحلقة التالية جاهزة</strong></summary>

للمسلسلات فقط: بعد انتهاء ترجمة الحلقة الحالية (أو أثناء انتظارها) يبدأ تجهيز الحلقة التالية في الخلفية، كما لو اخترتها بنفسك، وتظهر «AI ✓» في قائمتها حين تجهز. قابلة للإيقاف من الإعدادات.

</details>

<details>
<summary><strong>حارس الحلقة الخاطئة</strong></summary>

الحلقة المطلوبة معروفة من معرّف العمل (`tt…:2:3`)، ويُقارن بها شاهدان: اسم ملف الترجمة (`S03E12`) ودلائل في أول أسطر الملف.

- **قبل القائمة:** يُستبعد الملف الخاطئ؛ وإن كانت كل الملفات لحلقات أخرى، يظهر سطر يوضح ذلك بدل قائمة فارغة.
- **عند الاختيار:** يُبحث في الحلقات المجاورة (نفس الموسم، ±3) عن ملف يطابق حلقتك.
- **إن لم يُوجد:** رسالة واضحة، ولا تُصرف توكنز على الحلقة الغلط.

لا يُدان ملف إلا بشاهد صريح: رقم حلقة بلا رقم موسم لا يدين (ترقيم الأنمي المطلق)، واسم الحلقة شاهد إيجابي فقط.

</details>

<details>
<summary><strong>فصل حزم الحلقات 1–13 تلقائياً</strong></summary>

بعض الترجمات تُرفع كملف واحد يجمع الموسم (`S01E01-E13`، `1-13 Complete`). كل حلقة تعيد التوقيت إلى `00:00`، والفرز الزمني كان يكدّس الحلقات فوق بعض داخل 24 دقيقة، فتظهر ترجمة الحلقة الأولى مهما كانت الحلقة المطلوبة.

الآن تُقرأ الأسطر **بترتيب الملف الأصلي**، وتُكتشف الحدود من رجوع التوقيت، أو عناوين `Episode N` داخل الملف، أو فجوات زمنية، أو تقسيم زمني حين يذكر الاسم مدى الحلقات. تُعرض أسطر الحلقة المطلوبة وحدها بتوقيت مصفّر، وينطبق ذلك على **الجاهز و AI والقائمة ومقارنة الجاهزات** عبر دالة واحدة. إن تعذّر تحديد الحدود بثقة، يُعرض إشعار صريح بدل ترجمة خاطئة. التفاصيل: [docs/PACKS-ar.md](docs/PACKS-ar.md).

</details>

### لماذا لا تُقرأ الترجمة المدمجة داخل الفيديو؟

المشغّل لا يسلّم الإضافات ملف الفيديو، بل معرّف العمل فقط، ومعه اسم الملف وحجمه وبصمته إن عرفها. لذلك لا تستطيع أي إضافة قراءة المسارات المدمجة؛ البديل هو جلب الترجمة المطابقة من الإنترنت.

## المزوّدون

أي خدمة تدعم `/chat/completions` بصيغة OpenAI. الصفحة فيها إعدادات جاهزة لـ **Gemini** و **OpenRouter** و **OpenAI**، وخيار «مخصّص» لغيرها، ومزوّد احتياطي يُستخدم مرة واحدة عند فشل الأساسي.

- بعض المزوّدين يرفضون حقولاً اختيارية (`reasoning_effort` أو `temperature` أو `response_format`)؛ مسار الترجمة يحذف الحقل المرفوض ويعيد المحاولة تلقائياً.
- نماذج OpenAI الحالية لا تقبل `temperature` أثناء التفكير ولا تعرف مجهود `minimal`: اختر «منخفض».
- **حين يرفض فلتر المحتوى سطراً:** الدفعة تُقسم إلى خمسة أجزاء، ثم إلى أصغر، حتى يبقى السطر المسبب وحده بلغته الأصلية. الأسطر المجاورة لا تضيع، وقائمة الأسماء تُقرأ على أربعة أجزاء عند الرفض. إن تجاوزت الأسطر المرفوضة 8% من الفيديو (و12 سطراً على الأقل) تتوقف الترجمة ويظهر السبب: هذا المزوّد لا يناسب هذا العمل.
- كل سطر مرفوض يكلّف نحو أربعة طلبات إضافية؛ إن كثر الرفض في عملٍ ما، استخدم مزوّداً آخر.

## الاختبارات والجودة

```bash
npm ci
npm test          # 269/269
npm run build     # يعيد بناء _worker.js و tarjuman-cloudflare.zip
```

- **269 اختباراً** تعمل بلا إنترنت، أمام مزوّد وهمي يحاكي الأعطال وصيغ الرفض المنشورة لـ OpenAI و OpenRouter، وأوهام SubDL و Jimaku و Kitsu و AniList.
- نسخة Cloudflare تُختبر داخل **workerd**، وهو المحرّك الذي تشغّله Cloudflare نفسها.
- **CI** يعمل على كل push إلى `main` وعلى كل وسم، ويبني الحزمة قبل الاختبار. **Release** يرفق `tarjuman-cloudflare.zip` بكل `v*`، مع إمكانية التحقق من `sha256` المنشور مقابل الملف المحلي.
- كتابة ذرية لملفات الحفظ، ومهلات مستقلة للمصادر الإضافية، وسقوف أحجام قبل فك الضغط.

## الحدود المعروفة

- لا تقرأ الترجمة المدمجة داخل ملف الفيديو (قيد في المشغّلات نفسها).
- المصدر الرئيسي يعتمد على IMDb؛ كتالوجات الأنمي تُقرأ لكن حارس الحلقة الخاطئة لا يُطبَّق عليها، والبحث عن الحلقات المجاورة يقتصر على نفس الموسم بحد ±3.
- SubDL مجاناً: 2000 بحث و50 تنزيلاً يومياً؛ Jimaku محدود لكل مفتاح، وترجماته غالباً إنجليزية (تُعامل كلغة مصدر إنجليزية).
- الصيغ المدعومة: SRT و WebVTT و ASS/SSA و ZIP. SubSource مؤجل حتى تتوفر API موثّقة تُختبر بمفتاح حقيقي.
- استخراج الأسماء يعتمد على النموذج؛ نموذج ضعيف قد يخطئ، والإضافة تعيد طلب السطر مرة واحدة ثم تقبله. ونموذج يعيد الأسطر كما هي لا يُنتج ترجمة «مكتملة» فتتوقف الترجمة ويظهر السبب.
- سلوك رفض المحتوى مُختبر أمام مزوّد وهمي، لا أمام مزوّد حقيقي. وفيلم كثير الأسطر المرفوضة قد يحتاج إعادة اختيار الترجمة أكثر من مرة على الخطة المجانية.
- الإضافة لم تُجرَّب داخل Nuvio نفسه؛ سلوكه مأخوذ من قراءة كوده المصدري. نسخة Cloudflare جُرّبت على حساب مجاني حقيقي: القوائم، قراءة الأفلام، إبقاء الاتصال حياً، وحلقة كاملة.
